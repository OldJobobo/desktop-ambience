# Desktop Ambience v0.4.0 Release Evidence

Date: 2026-08-19

## Result

Phase 6 passed. The plugin met the release matrix without changing live Desktop Ambience settings, Omarchy shell configuration, or persistent Hyprland monitor configuration.

## Environment

- Omarchy Shell with Quickshell on Wayland
- Hyprland 0.56.2
- Three physical outputs
- Resolutions: 2560×1440 and 1920×1080
- Landscape and portrait transforms
- Temporary headless output at 1.25 scale and portrait transform
- Physical refresh transition tested from 60 Hz to 180 Hz and restored to 60 Hz

## Automated and lifecycle checks

- Full repository suite: 68 tests and 4 subtests, zero skips
- Manifest validation and QML lint passed
- Forbidden dependency and file-owner scans passed
- Clean Git clone validated as an installable plugin root
- Plugin rescan retained three mapped surfaces
- Shell restart restored exactly one surface and one layer per output
- Headless hotplug completed 3 → 4 → 3 surfaces without duplicates
- Settings and shell configuration hashes were unchanged

## Visual matrix

The isolated visual harness rendered:

- Aurora Drift
- Cinematic Light
- CRT
- Dust Motes
- Film Grain
- God Rays
- Rainfall
- VHS / Tracking Lines
- Dedicated vignette
- Three-effect stack
- The same active stack after a theme switch

Every image was non-empty and non-flat. Manual contact-sheet review confirmed the expected visual signature for each effect, a visible dedicated vignette, a composed three-effect stack, and a palette change after the live theme switch.

See [`evidence/0.4.0/contact-sheet.webp`](evidence/0.4.0/contact-sheet.webp) and [`evidence/0.4.0/visual-performance.json`](evidence/0.4.0/visual-performance.json).

## Fullscreen and coexistence

A disposable window and isolated foreground panel ran beside the installed plugin on a temporary output.

- Normal: paint allowed
- Fake fullscreen (`internal=0`, `client=2`): paint remained allowed
- Real fullscreen (`internal=2`, `client=2`): paint suppressed on that output
- Return to normal: paint resumed
- The ambience surface remained mapped for every transition
- The isolated and installed effect systems coexisted without duplicate ownership or stale surfaces

## Performance evidence

The performance sample uses an isolated Quickshell process rendering the three-effect stack at 1920×1080. It is not a plugin-only measurement from the complete desktop shell.

Final values are recorded in [`evidence/0.4.0/visual-performance.json`](evidence/0.4.0/visual-performance.json). Phase 6 records inherited renderer cost but does not claim an optimization or cross-machine performance guarantee.

## Recovery coverage

The complete suite covers malformed settings, last-valid-state retention, atomic latest-write-wins persistence, interrupted-save retry, theme-path replacement, reorder without renderer recreation, launcher persistence, and settings restart round trips using temporary XDG homes.

## Residual risks

- Dynamic effects are not compared against immutable per-frame golden images because timers, noise, output geometry, and GPU rendering vary. Provenance contracts, non-flat captures, hashes, and manual contact-sheet review provide the release evidence instead.
- CPU and memory figures describe the isolated render harness, not an attribution of total desktop-shell resource use to this plugin alone.
- Marketplace-style installation from a public remote remains unavailable until a public Git remote is configured. Local Git installation, update, disable, removal, cleanup, and clean-clone validation have passed.
