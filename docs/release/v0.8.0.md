# Desktop Ambience v0.8.0 Release Evidence

Date: 2026-08-23

## Result

The complete automated, Phase 7, and Phase 6 release matrices passed for v0.8.0. This release adds Drip as the twelfth ordered renderer and polishes the settings experience with effect-level reset, session-only preview pausing, human-readable enum labels, stronger visual hierarchy, and clearer active/available effect selection.

Drip is opt-in. Existing settings retain their schema version, active order, unknown JSON-safe fields, Bokeh and Node Mesh defaults, and Rainfall precipitation values.

## Release scope

### Drip

Drip is a bounded, theme-aware edge effect with automatic bar-aware direction, explicit upward or downward overrides, screen-edge fallback, configurable population and timing, live speed retiming, reduced-motion static output, and an opt-in cinematic blood mode. Bar geometry is injected by the panel; the renderer owns no shell or file-reading process.

### Settings polish

The settings window adds scoped effect reset and a session-only **Pause preview** action that suspends renderer paint and shared cursor sampling without changing persisted enablement. Enum controls show human-readable labels while retaining stable persisted values. The composition and detail panes use Omarchy-native state fills, borders, spacing, selection colors, and a persistent detail header.

## Compatibility

- `manifest.json` is the canonical version source and reports `0.8.0`.
- Existing settings and ordered stack positions remain compatible.
- Drip gains a normalized default payload without being inserted into active stacks.
- Bokeh, Node Mesh, and Rainfall precipitation behavior from v0.7.0 remains intact.
- Pause Preview is session-only and writes no settings state.

## Automated and live validation

- `./scripts/check.sh`: 159 tests and 4 subtests passed with zero skips.
- `./scripts/check-contracts.sh`: 98 tests passed, with two active-session BarWidget behavior tests excluded by the host-independent filter.
- `JOBO_AMBIENCE_LIVE_PHASE7=1 ./scripts/check-phase7.sh` completed 42 cases across one and three outputs, producing 84 performance cells.
- Phase 6 rendered 59 cases. Its 240-frame visual cadence sample averaged 16.67 ms, peaked at 18.44 ms, and recorded no callback over 20 ms.
- Drip default, maximum-population, and reduced-motion cases ran on one and three outputs with bounded delegate counts of 28/72 per output.
- Three-output Drip measured 28.54% CPU at default population, 41.49% at maximum population, and 0.81% under reduced motion on this machine.
- Fullscreen suppression, lifecycle, headless hotplug, mixed-resolution output modes, negative-origin Node Mesh ownership, and rain/snow multi-output checks passed.
- Live settings, shell configuration, and persistent Hyprland monitor configuration were unchanged at postflight.

## Hardware and operational notes

- Physical coverage included three outputs, mixed resolution, and portrait rotation at 1× scale and 60 Hz.
- Mixed scale, mixed refresh, variable refresh, HDR/color-managed output, and subjective foreground layering remain manual risks.
- Performance results are machine-local directional evidence rather than portable budgets.
