# Desktop Ambience v0.5.0 Release Evidence

Date: 2026-08-19

## Result

Phase 7 passed. Version 0.5.0 adds per-effect performance characterization, replaces per-output Dust Motes cursor polling with one persistent panel-owned tracker, corrects partial first animation cycles caused by unstable startup geometry, and stabilizes live God Rays controls. Visual intent and persisted settings contracts remain intact.

## Shared cursor ownership

`services/CursorTracker.qml` is the only runtime owner of cursor sampling. Every per-output Dust Motes renderer receives its coordinates, velocity, and kick through `AmbienceStack.qml`.

The tracker remains stopped unless Dust Motes is selected, enabled, mouse-reactive, non-zero intensity, global ambience is enabled, reduced motion is disabled, and at least one surface can paint. Runtime IPC reports tracker active/running state, launches, failures, and the latest error.

## Measured result

The immutable `v0.4.0` worktree and the candidate were profiled with the same current harness, temporary XDG homes, fresh Quickshell processes, and reversible headless outputs.

Five repeated Dust Motes samples produced:

| Measurement | `v0.4.0`, 1 output | v0.5.0, 1 output | `v0.4.0`, 3 outputs | v0.5.0, 3 outputs |
| --- | ---: | ---: | ---: | ---: |
| Median CPU | 4.99% | 7.84% | 8.97% | 10.59% |
| Median frame callback | 16.61 ms | 17.26 ms | 16.95 ms | 17.14 ms |
| Cursor launches per two-second sample | estimated 17 | 17 exact | estimated 50 | 17 exact |

The final short-sample rerun did not reproduce the earlier CPU reduction, so CPU remains a directional local measurement rather than a release target. The ownership result was exact: cursor launches stopped multiplying with output count.

The full baseline identified Rainfall as the most expensive individual renderer. It remains a separately scoped follow-up because renderer rewrites must be independently reviewable and revertible.

See [`../performance/phase7.md`](../performance/phase7.md) for methodology, limitations, and the complete ranking.

## Automated and live validation

- Full repository suite: 82 tests and 4 subtests, zero skips
- QML lint, manifest validation, forbidden-dependency scans, and clean-clone validation passed
- Every effect, vignette, three-effect stack, and active theme switch rendered successfully
- Renderers waited for stable non-zero geometry before starting their first loop
- Rainfall populated both halves of the output during its first captured cycle instead of cascading from above-screen partial paths
- Aurora Drift secondary glows began at their animated opacity floor and all ribbons entered motion together without delayed layer transitions
- God Rays used a continuous motion clock and persistent delegates, keeping activation and live speed/ray-count edits smooth
- Active-stack selection used one Omarchy-native selected surface plus the standard semantic hover treatment
- Visual contact-sheet review preserved the intended v0.4.0 appearance while correcting startup motion
- Three physical outputs plus reversible headless outputs passed lifecycle checks
- Mixed resolution, orientation, fractional scale, and 60 → 180 → 60 Hz refresh restoration passed
- Plugin rescan and shell restart restored exactly one mapped surface per output
- Real fullscreen suppression, fake fullscreen, and restoration passed
- Live settings, shell configuration, and persistent Hyprland monitor configuration were not modified

## Residual risks

- The shared tracker still launches one short `hyprctl cursorpos` process every 120 ms while required; Phase 7 removes output-count multiplication rather than introducing an unproven input helper.
- CPU and frame values are machine-local. Repeated targeted medians support the cursor result, but individual full-matrix rows remain directional single samples.
- Rainfall is the next measured optimization candidate; no shader or particle rewrite is included in this release.
- No public Git remote is configured, so the local annotated release tag cannot be pushed yet.
