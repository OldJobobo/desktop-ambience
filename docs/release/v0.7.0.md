# Desktop Ambience v0.7.0 Release Evidence

Date: 2026-08-20

## Result

The complete automated, Phase 7, and Phase 6 release matrices passed for v0.7.0. This release adds Bokeh and Node Mesh as the tenth and eleventh ordered renderers, adds selectable rain and snow styles behind the existing `rainfall` renderer, and prevents wheel or touchpad scrolling over settings sliders from changing values.

Bokeh and Node Mesh remain opt-in. Existing Rainfall users retain `rain` as the normalized default with their persisted values and stack order unchanged.

## Release scope

### Bokeh

Bokeh is a deterministic, theme-aware bounded light field split across three grouped blur layers. It supports configurable population, size, softness, drift, twinkle, speed, and palette roles. Reduced motion is static, and hidden, transparent, disabled, removed, or fullscreen-suppressed renderers stop autonomous animation.

### Node Mesh

Node Mesh is a deterministic simulation capped at 30 accepted updates per second, 120 nodes, four incident connections per node, and a derived 240-edge ceiling per output. Eight retained declarative `ShapePath`/`PathMultiline` buckets render connections. Optional attraction and repulsion reuse the single panel-owned cursor tracker and apply only on the output owning the raw cursor sample, including negative-origin layouts.

The production pixel probe proves that connection lines render and that distance and opacity controls change visible pixels. The render-equivalent benchmark selected retained Shape paths over Canvas on the installed Qt/Quickshell runtime.

### Precipitation styles

The existing `rainfall` ID now selects `rain` or `snow` through normalized registry metadata. Extracted rain is pixel-exact against the pinned pre-extraction static and animated captures. Snow uses deterministic full-height flake seeding, bounded depth/detail variation, and one shared 30 Hz clock rather than per-flake clocks.

Rain- and snow-specific settings use generic `visibleWhen` enum metadata. Hidden controls retain their normalized values. The persisted `dropCount` key and bounds are unchanged while its UI label is **Precipitation Count**.

### Settings slider input

Numeric settings use a drag-only slider. Mouse-wheel and touchpad deltas scroll the containing settings list; values change only through a left-button click or drag.

## Compatibility

- `manifest.json` is the canonical version source and reports `0.7.0`.
- Existing settings keep schema version, active order, unknown JSON-safe fields, and Rainfall values.
- Bokeh and Node Mesh gain default payloads without being inserted into active stacks.
- Rain and snow remain internal styles of the existing `rainfall` effect; its ordered ID, stack position, and root object contract remain stable.
- Invalid precipitation style/detail values normalize to supported defaults.
- Node Mesh adds no cursor process. One panel-owned sampler serves every requesting effect and output.

## Automated and live validation

- `./scripts/check.sh`: 142 tests and 4 subtests passed with zero skips.
- `./scripts/check-contracts.sh`: 92 tests passed, with the two active-session BarWidget behavior tests intentionally excluded by the host-independent contract filter.
- `JOBO_AMBIENCE_LIVE_PHASE7=1 ./scripts/check-phase7.sh` passed. This command generated the complete 39-case, one-/three-output Phase 7 matrix and its embedded complete Phase 6 matrix.
- Phase 7 recorded 78 four-second cells at negative output origins. Every hidden, reduced-motion, and fullscreen-suppressed shutdown contract passed.
- Phase 6 rendered 58 cases. Its 240-frame visual cadence sample averaged 16.67 ms, peaked at 19.47 ms, and recorded no callback over 20 ms.
- Bokeh, Node Mesh, precipitation, and whole-stack theme-switch captures all changed visible pixels.
- Fullscreen suppression preserved Bokeh, Node Mesh, and Rainfall root identities, kept surfaces mapped, and stopped each renderer while suppressed.
- Node Mesh and precipitation two-output probes passed nonblank/distinct capture, negative-origin, compositor-assignment, and ownership/static-state checks.
- Three physical outputs passed lifecycle validation, including mixed resolution and portrait orientation. Plugin rescan, shell restart, one-layer-per-output checks, and reversible headless hotplug passed.
- Live Desktop Ambience settings, persistent monitor configuration, and shell configuration were unchanged at the required matrix's immediate postflight checkpoint. No temporary `JOBO-*` outputs remained.

## Directional performance

The v0.7.0 Phase 7 matrix is machine-local directional evidence, not a portable budget.

| Scenario | 1 output CPU | 3 outputs CPU | Notable result |
| --- | ---: | ---: | --- |
| Bokeh default | 7.01% | 8.95% | Mean callback 16.67 ms; no callbacks over 20 ms |
| Bokeh maximum population | 10.25% | 15.35% | Maximum callback 17.99 ms |
| Node Mesh default | 5.12% | 9.19% | Three-output maximum callback 33.62 ms |
| Node Mesh maximum | 10.25% | 20.72% | Bounded at 120 nodes and 8 retained paths per output |
| Rain default | 27.18% | 35.76% | Mean callback 16.66 ms |
| Rain maximum population | 58.85% | 71.91% | Maximum callback 17.99 ms |
| Snow default | 11.00% | 19.22% | Three-output maximum callback 23.41 ms |
| Snow maximum population | 18.21% | 32.78% | Three-output maximum callback 27.22 ms |
| Precipitation switch churn | 38.90% | 76.62% | Worst case: 18.68 ms mean, 89.49 ms maximum |
| Three-effect stack | 38.85% | 52.69% | Three-output maximum callback 23.04 ms |

The full matrix ranged from 2.16% to 76.62% CPU and 328.7 to 442.0 MiB peak RSS. Static, hidden, reduced-motion, and fullscreen-suppressed cases performed zero prohibited autonomous work. Cursor launch counts did not multiply with output count.

The three-output precipitation style-switch churn remains the heaviest measured case. It is bounded test churn rather than normal steady state, but its 89.49 ms maximum callback is retained as an explicit residual performance risk.

## Hardware and operational notes

- Physical coverage included three outputs, mixed resolution, and portrait rotation at 1× scale and 60 Hz. Mixed scale, mixed refresh, variable refresh, and HDR/color-managed output remain manual risks.
- Foreground/background layering and snow detail remain subjective physical-output review items.
- A redundant second Phase 6 invocation was mistakenly attempted immediately after the already-successful embedded Phase 6 run. Its lifecycle preflight encountered temporarily unavailable shell IPC and was not used as release evidence. A fresh shell recovered to v0.7.0 with all three surfaces mapped.
- The successful required matrix recorded identical preflight and immediate-postflight hashes. A later fresh-shell startup reordered two unrelated `jobo.sidebar` widget records (`hass` and `robzolkos.github`); that concurrent state was left untouched and is not attributed to Desktop Ambience validation.
